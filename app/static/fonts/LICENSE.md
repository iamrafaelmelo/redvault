# Fontes incluídas neste diretório

Todos os arquivos `.woff2` são subsets (latin + latin-ext) servidos localmente pela
plataforma — o navegador nunca faz download em runtime.

| Família | Uso | Autor / origem | Licença |
| --- | --- | --- | --- |
| Inter | texto corrido (UI) | Rasmus Andersson — https://rsms.me/inter/ | SIL OFL 1.1 |
| Space Grotesk | títulos | Florian Karsten — https://fonts.google.com/specimen/Space+Grotesk | SIL OFL 1.1 |
| JetBrains Mono | código e dados técnicos | JetBrains — https://www.jetbrains.com/lp/mono/ | SIL OFL 1.1 |

Os arquivos foram obtidos via Google Fonts e convertidos para subsets. Nenhuma
modificação de desenho foi feita; apenas subsetting, que a OFL permite.
